The problem, precisely

Agents pay retail for information the repo already summarized.

Every mainstream agent loop burns tokens on three things that never needed to be tokens: whole-file reads for one function, raw shell output, and asking a frontier model whether tests passed.

50–99%
of file-read tokens

are boilerplate the task never touches. Reading a whole file to reach one function is the single most common waste pattern in agent traces.

60–90%
of exec output

is compiler noise, progress bars, and warnings. A regex knew it was noise. Your agent paid list price anyway.

$0.00
correct cost of "did tests pass?"

A local parser answers pass/fail deterministically. Sending test logs to a frontier model to summarize is burning dollars to avoid writing ten lines of regex.

Honesty clause: the percentages above are our fixture-bench measurements under controlled conditions. Live sessions run lower — cold caches, novel files. Every claim on this page carries its measurement basis, and your dashboard shows your live numbers, not ours. If a vendor quotes you one unqualified multiplier, close the tab.
Mechanics

Four moves between the agent and the file system.

No magic, no agent-side SDK. The tools replace built-ins at the protocol level; your existing client discovers them automatically.

01

Content-addressed reads. Re-reads during a session cost zero tokens — agents re-read constantly.

Command-shaped output rules: compilers, test runners, git, package managers. Structured results, not raw dumps.

Code intelligence

Grep finds text. Graphs find consequences.

Every attached repo gets continuous indexing: tree-sitter symbol tables, dependency graphs, cross-references. Retrieval expands along those edges before anything reaches a model.

Symbols, not strings

Rename-safe navigation over AST-extracted definitions, references, implementations — ranked by graph distance to what the agent is already touching.

Graph-expanded retrieval

Vector search proposes candidates; the call/dep graph pulls in callers, callees, and behaviour siblings within N hops. The model sees the relevant neighborhood, not fifty near-misses.

Impact queries

"What breaks if I change this function?" answered by walking edges computed at push time — not by hoping the model memorized your architecture.

Language modules bolt on per workspace

The core speaks tree-sitter for broad coverage. Attach a language module and the workspace gains its native intelligence. Elixir, for instance — where BEAM hands you structure other ecosystems have to infer:

Tool tables vary per workspace — attach the Elixir module and sup_tree appears; detach it and it's gone. Clients negotiate schemas by version, so nothing breaks when a module lands. That negotiation surface shipped before this product did; it's load-bearing, not aspirational.

Context engine

Documentation that knows who's asking.

Architecture notes, decisions, runbooks — stored as structured rows with provenance and staleness columns, compiled into markdown variants per visibility tier, and served over a virtual filesystem your agent can Read and Grep like any other directory.

// the loop
git push ──▶ graph nodes touched ──▶ knowledge rows marked stale
                                              │
                     incremental rebuild ◀────┘   (classic SSG build, nothing exotic)
                              │
              ▼ variant matrix: one MD render per visibility tier
              ├── /context/public/payments-overview.md      ← doubles as your docs site
              ├── /context/member/payments-overview.md
              ├── /context/team-payments/payments-overview.md   ← includes the rate-limit internals
              └── /context/admin/payments-overview.md           ← includes the incident timeline

The field is the ACL, not the file

A wiki page is visible to everyone or no one. Here each section carries its own tier; the contractor-grade render simply omits what a contractor must not see — and never learns that anything was omitted. Rights evaluate server-side against the caller's principal on every MCP request.

Permission correctness is a build gate

Because variants are static artifacts, CI scans every render and fails the build if an artifact contains sections above its tier. Scoped access stops being a runtime promise and becomes a checked invariant — with a diff trail for your auditors.

Agents write rows, not prose

Agent-contributed knowledge lands as structured entries through review — provenance-tagged, source-commit-linked — instead of freehand edits slowly wrecking a markdown file nobody diffs.

Stale is a trigger, not a vibe

Knowledge rows link to code-graph nodes. Change the code, the linked rows flag themselves, affected variants rebuild incrementally, and readers get last-known-good plus a staleness header.

Why markdown? Because it's the format agents already consume best and humans already review cheapest. We didn't invent a knowledge format; we invented supply chain for one.
Trust

The boring security decisions, made explicitly.

Two-stage egress guard

Every byte leaving the server passes deterministic secret detection first — prefix rules, checksum validators, entropy windows — then a small local NER model for contextual PII that regexes miss. Deterministic catches stay deterministic; the model never gates alone.

SSRF hardened by construction

Outbound fetches are host-allowlisted, DNS-resolved and re-validated against private ranges, redirect-checked per hop, with subresource classes blocked at the engine level. Built for hostile input, documented in the threat model.

Audit everything, enforce budgets

Per-call audit log: which principal, which tool, which repo, how many tokens, what was redacted. Hard token/cost ceilings enforced at the gateway per user, team, or repo — the cutoff fires before the invoice does.

Self-host escape hatch

Hosted: your code is indexed in an isolated per-repo worker; nothing trains anything, ever. Want bytes to never leave your VPC? Run the same binary against your own object storage; hosted becomes control-plane only.

Architecture

Two-tier deployment

Senkani hosted runs as a coordinated two-tier system. The web tier is a remote MCP endpoint that indexes remote repos, aggregates team savings metrics, and enforces budgets and audit policies. The local tier is a thin agent running in each developer's worktree that caches index data for their checked-out branches, supports offline work, and writes changes back to the remote tier when ready. This division of labor lets teams share index warmness for cost efficiency while letting individuals keep WIP experiments private and offline.

Web tier

  • Hosted MCP endpoint, reachable from any client
  • Shared per-repo MiniLM/LSM indexes across the team
  • Savings dashboard & budgets, hard cutoffs at gateway
  • SSO/SAML, audit export, DPA

Local tier

  • Git worktree-scoped index cache
  • Offline mode — queries work without network
  • WIP branches never pollute team-shared state
  • On-push, selectively push index updates to web tier
Synchronization: On push, the local tier pushes incremental index diffs to the web tier for the updated repo. On checkout/switch, the local tier warms its cache from the web tier. The web tier never contains a developer's private WIP index unless they explicitly push it.

Objections, pre-answered

Frequently asked, aggressively.

Is the big multiplier real?

The fixture number (80×, synthetic, controlled) is the optimization math's ceiling. Live-session replays land meaningfully lower because real work reads novel files and pays cold-start indexing. Both numbers ship together on every surface we control, and your dashboard reports your live floor — which is the only number that affects your bill. Anyone selling you a single unqualified multiplier is selling you their best day.

Can't a good prompt solve this?

A prompt changes how the model asks. It cannot change what Read returns. When the unit of transfer is a 1,800-line file and the need is 55 lines, no amount of instruction fixes the metering. We changed the metering.

Another vector DB with a chat wrapper?

No. Embeddings are one fusion input among deterministic systems: content-addressed caches, command-shaped filters, AST extraction, and computed graphs. Retrieval quality was never the bottleneck — transfer volume and access control were.

What do my agents need installed?

Nothing. Any MCP-capable client — Claude Code, Cursor, your homegrown harness — points at the endpoint URL with an OAuth token. Tools are discovered at connect time; schema versions negotiate cleanly when we ship new capabilities.

Which languages get graph intelligence?

Tree-sitter grammars cover the mainstream set on day one: symbols, outlines, dep graphs, semantic search. Deep native modules (diagnostics, xref precision, runtime topology) land per language — Elixir first, because BEAM's explicit structure makes the value obvious. Tell us yours; the module API is the roadmap, not a secret.

What happens to my data?

Hosted: isolated per-repo index workers, egress scanning on every response, per-call audit, zero training on your content — contractual, not vibes. Self-hosted: index and storage run in your VPC; we see control-plane telemetry only. The local binary is the same code path with the network cable pulled.
